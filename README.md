# ESTHER project website

Project page for **ESTHER: Egocentric Stereo Hand Estimation and Reconstruction in the Wild**.

Hosted at https://fruitrabbit.github.io/esther/ via GitHub Pages.

Static HTML, CSS, and JavaScript. To preview: `python3 -m http.server 8765` from this directory.

Code and dataset release sections are marked **Coming soon**. This repository contains the project website, not the model implementation or dataset.

The paper download includes the main text and supplementary material. Demo footage is rectified using the matching per-scene camera calibration. The web video is compressed from the approved 52-second edit without changing its content.
